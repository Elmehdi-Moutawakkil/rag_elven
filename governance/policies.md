# Governance Policies

Initial project rules:

1. No generated content becomes canon automatically.
2. Canon, generated drafts, pending memory, validated memory, rejected content,
   and fanon must remain separate.
3. Real API keys must never be committed.
4. Broad read access is acceptable; write access must be limited by tool,
   permission, and target.
5. Validation should be traceable to sources, Knowledge Graph checks, or human
   review.
